## 1. Theorem 4.11 (counting bound at every filling): correct, after (R1) to (R3)

### 1.1 The comparison principle

C200 does not re-prove C149's M-function theorem and does not need it. Part 1 restates C149 Theorem 1.1 (line 32), tagged [rigorous] although C149 was never refereed, but the only comparison statement used anywhere is Lemma 1.1 (lines 34 to 40), whose proof is self-contained. I re-derived it. If j maximizes x*_j - y_j > 0 over the finite nodes, then x*_j - x*_k >= y_j - y_k for finite k, so theta(x*_j - x*_k) <= theta(y_j - y_k) since theta is nonincreasing (theta' = -2 pi T < 0); for a node at infinity, theta(x*_j - x*_k) < theta(-inf) = pi - 2 eta; and p(x*_j) > p(y_j). Hence 0 = F_j(x*) > Ft_j >= 0. The argument uses only that p is increasing and theta is nonincreasing and bounded above by pi - 2 eta. It needs no ordering of the nodes, no condition at the infinite nodes, and no M-matrix structure. Proposition 4.7, the only other place a comparison is invoked, is the case with no infinite nodes. Repair (R2): replace line 32 by a pointer to Lemma 1.1, or retag it as cited from unrefereed C149. Uniqueness of the real zero, which the reflection step uses, also follows from Lemma 1.1 applied in both directions (and from strict convexity of the Yang-Yang action, whose Hessian is the Jacobian, strictly diagonally dominant with positive diagonal at every configuration).

Legitimacy of the trial inputs. Every trial node in C200 is either a real number or +infinity. The exterior nodes of Theorem 4.11 are z_i = Q + iH, H = A d, with i = 1, ..., M an integer index (PROOF line 266); they are real. The question in the commission about "complex positions Q + iAd" comes from this notation, and nothing in the proof places a node off the real axis. Nodes at +infinity are inputs to Lemma 1.1 only through the constant n_inf (pi - 2 eta) in Ft_j, which is the limit theta(-inf); Lemma 1.1 is stated and proved for this extended configuration, so they are legitimate. Repair (R3): write the exterior nodes as Q + l A d, l = 1, ..., M, in RESULT.md and PROOF.md.

### 1.2 Lemma 4.10 and the residual identity

Correct. I re-derived (4.2) from scratch. With D = L N_0 - #{finite nodes <= v}, the Stieltjes integration by parts against Theta(y - v) produces a boundary term +n_inf q/2 at v = +inf that cancels the -n_inf q/2 of the infinite nodes, giving Ft_j/(2 pi) = t(y_j) - n/2 - I_j - int T(y_j - v) D(v) dv. The continuum identity L p(u)/(2 pi) + L int Theta(u - v) r(v) 1_[-Q,Q] dv = t(u) - n/2 follows from int Theta(u - v) dN_0(v) = T*N_0 - q nu/2. On [-Q, Q] the finite count is max(0, floor t - k), so D <= kappa + s#(t) (with equality once floor t >= k). Above Q, D = k - sum_i 1{v >= z_i}. Using int_{-Q}^{Q} T(y - v) dv = q - B(Q + y) - B(Q - y), the coefficients (1 - q) kappa, kappa B(Q + y), (1/2) B(Q - y) and the full tails B(z_i - y) come out as stated.

### 1.3 The supersolution inequalities, node by node

Exterior nodes, Case 1, step (c). Correct, and I checked the top node in particular. The constant parts of the interactions sum to q I_j (j - 1 nodes to the left at q/2 each, n - j to the right, finite or infinite, at -q/2 each). The identity L p(z)/(2 pi) = E_i + (1 - q) n/2 + int B(z - v) L r(v) dv follows from the continuum identity at z > Q. The right-endpoint quadrature bound, sum over the right endpoints of all n unit cells of B(z - v_c) <= int B(z - v) L r dv + B(z - Q), is a telescoping estimate for an increasing function, and the interior nodes are the right endpoints of cells k + 1, ..., n. With n/2 - I_j = k - i + 1/2 > 0 and B(l H) <= eta/(pi l A d), the bracket c_2 log(A i) - (1 + log i)/(pi A) is nonnegative for A >= e and 1/(pi A) <= c_2, for every i and independently of M. Step (b), E_i >= c_2 (eta/d) log(A i), uses x = iH <= R/4 <= min(Q, 1)/4 (so that Q - u >= 0 and u + w <= 1/2) and L r(Q - u) >= 1/ell >= 1/d for ell <= u <= Q, both satisfied in Case 1.

Interior nodes. Correct in each subcase. For 0 < y < Q with delta = Q - y < 1 in Case 1: delta >= ell because t(Q) - t(y) is a positive integer, so rho(y) >= max(delta, d) and z_i - y = delta + iAd <= rho(y)(1 + iA), with eta <= z_i - y <= 5/4 inside the range of (4.3). The harmonic sum b sum_{i <= M} 1/(1 + iA) diverges, so M covers C_S. For delta >= 1, (1 - q) kappa = 2 eta kappa/pi covers C_S eta. For y <= 0 the left exterior gives kappa c eta/min(1, eta + Q + y) by (4.3). At y = Q, |S(Q)| <= (1/2) int_0^{2Q} T <= q/4 = B(0)/2. In Case 2 (R < 4AMd), min(1, eta + Q + y) <= min(1, eta + 2R) <= (1 + 8AM) min(1, d) <= (1 + 8AM) rho(y), so the left exterior covers C_S eta/rho once c kappa >= (1 + 8AM) C_S. I also checked the case Q > 1 inside Case 2 (then rho(y) >= min(1, d) > 1/(4AM) and the twist gain alone suffices) and Q < eta (always Case 2).

Kernel bounds (4.3). Correct: T(w) <= eta/(pi w^2) for all w > 0 from sinh w >= w and sin 2 eta <= 2 eta, and T(w) >= c_1 eta/w^2 on eta <= w <= 4.

### 1.4 Is K finite and universal?

Yes. The constants are fixed in this order, each from the previous ones only: c_1, b, c (kernel bounds, absolute); C_S (Theorem 4.3, from the Harnack and interior-derivative constants for discs, which are scale invariant); c_2 = c_1/4; A = max(e, 1/(pi c_2)); M with b sum_{i<=M} 1/(1 + iA) >= C_S; kappa >= max(pi C_S/2, C_S/c, (1 + 8AM) C_S/c); k = max(M, 2, ceil(kappa - 1/2)); K = k + 1. None depends on eta, Q, L or n. I looked for degenerations at the three places named in the commission. At a sparse Fermi edge, ell >> eta, the scale d = max(eta, ell) absorbs it, and when the exterior range no longer fits (MAd > R/4) Case 2 takes over with the left exterior. At small filling, n <= k is trivial and n > k forces n >= 3, which puts the last cell in the right half (0 < ell < Q). Near half filling (odd L, n = (L - 1)/2, Q of order log L) everything is uniform in Q, with R = 1 and the twist gain covering rho = 1. Theorem H covers only even L at n = L/2 and is not needed elsewhere. The constant is not explicit because C_S is not, as RESULT.md says.

Repair (R1). Step (a) uses "r is nonincreasing on [0, Q]" without proof or citation. The same fact is used in step (b) (the bound L r(Q - u) >= 1/d needs Q - u in the right half), in Corollary 4.13 Steps 6 and 7 (K_c is an interval, int |r'|/r^2 = 2[1/r(x_c) - 1/r(0)], the tail is an interval), and in (I4)(iv) (r(Q)/r <= 1). It is proved in C136 Section 2 (level-set argument, confirmed by the C136 referee) and also follows in two lines from (I4)(i) and (ii): r' = R a1' - r(Q)(G - H) with R a1' <= 0 and G - H >= 0 on [0, Q] by positivity of the odd resolvent. My continuum solver finds max r' < 0 on (0, Q] in all 24 cases of check_cont_thms.py. Cite it.

## 4. Theorem 4.2: correct after (R4)

The harmonic representation is right. P_h(x) = -(1/pi) Im coth(x + ih), so U(x, h) = (P_h * f)(x) + (P_{pi/2 - h} * g)(x) is harmonic in 0 < h < pi/2, with U(x, 0+) = f(x) and U(x, pi/2) = g(x). The Fourier identity (sinh(eta k)/sinh(pi k/2)) (1/(2 cosh(eta k/2))) = sinh(eta k/2)/sinh(pi k/2) is correct, so P_{pi/2 - eta} * g = a1 and U(., eta) = s. The continuum equation is U(x, 0) = U(x, eta) on |x| < Q, which makes V_h(x, 0) = 0 for the vertical average V. The Harnack argument is sound and the constants are uniform as eta -> 0: every disc used has radius proportional to its distance from the boundary of the domain of harmonicity (eta/2 about (y, eta); R = min(delta/2, 1/4) about (y, 0) for the reflected V; N eta/2 about (y, N eta)), so only the scale-invariant disc constants enter, and the telescoping U(x, eta) = U(x, N eta) - eta sum_{l<N} V_h(x, l eta) costs N eta C R^(-j-1) s <= C R^(-j) s. The case split R < 16 eta (then rho <= 33 eta) uses eta <= 1/64 only to exclude R = 1/4 < 16 eta. Repair (R4): the even reflection of V across the segment requires V continuous with V_h continuous up to the segment and vanishing there; this holds because f = r is continuous on (-Q, Q) and U(x, h) -> f(x) locally uniformly there, and the discs used stay at distance R < delta from the segment's endpoints. One sentence in the proof would close it. Numerically (own solver): sup |r'| rho/r <= 1.21 and sup |r''| rho^2/r <= 1.72 over the same 24 cases, with no growth as eta decreases.

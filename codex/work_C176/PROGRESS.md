- Design decision (PROOF 1). A bond label (N, f) with f the occupation of the site to the left, used on both sides of the centre, does not give an orthonormal right basis (right states with f = 0 and f = 1 overlap), so it would make the Schmidt values wrong. The code instead uses left-physical labels (N_left, n_{i-1}) on left-canonical tensors and right-physical labels (N_right, n_i) on right-canonical tensors. Both bases are then orthonormal, the blockade and N are structural zeros, and the truncation respects the labels.

# Reproducing the main checks

All commands run from this directory and use only generated code. The larger jobs can take several minutes. Individual JSON outputs are overwritten when their script is rerun.

The exact two-body threshold and disappearance of the molecular minima are reproduced by

```sh
OPENBLAS_NUM_THREADS=1 python3 pair_threshold.py
OPENBLAS_NUM_THREADS=1 python3 detuned_pair_bands.py
OPENBLAS_NUM_THREADS=1 python3 pair_saddle.py
```

The implementation checks are

```sh
OPENBLAS_NUM_THREADS=1 python3 momentum_ed.py
OPENBLAS_NUM_THREADS=1 python3 test_dmrg.py
OPENBLAS_NUM_THREADS=1 python3 test_canonical_dmrg.py
OPENBLAS_NUM_THREADS=1 python3 test_periodic_dmrg.py
```

The main finite-density periodic spectra and entropy data are generated by

```sh
OPENBLAS_NUM_THREADS=1 python3 momentum_scaling.py
OPENBLAS_NUM_THREADS=1 python3 ed_scaling.py 0.9
OPENBLAS_NUM_THREADS=1 python3 ed_L24.py
OPENBLAS_NUM_THREADS=1 python3 finish_L24_sectors.py
OPENBLAS_NUM_THREADS=1 python3 calibrate_periodic.py
```

The translation-resolved script is substantially faster than full-charge-sector ED at L=21. The L=24 program examines selected momenta first; finish_L24_sectors.py supplies the remaining sectors. The generated ed_L24_remaining_sectors.json should contain all eight requested sectors for a complete check.

The periodic DMRG test point can be started with

```sh
OPENBLAS_NUM_THREADS=1 python3 periodic_dmrg.py --L 24 --N 8 --delta 0.9 --chi 96 --sweeps 12 --output periodic_L24_N8_d09
```

Saved states can be refined with resume_periodic.py. It reconstructs conserved bond charges from the saved tensors and checks them before continuing. For example,

```sh
OPENBLAS_NUM_THREADS=1 python3 resume_periodic.py --L 24 --N 8 --input periodic_L24_N8_d09 --output repeat_L24_refined --schedule 128,192,256,256 --seconds 1500
```

This script has an explicit wall-clock alarm. A stopped job retains its last complete-sweep JSON and MPS checkpoint. A small discarded weight alone does not establish convergence in this model. Compare energy and entropy against the L=24 ED values in RESULT.md.

The diagnostic figure is rebuilt with

```sh
OPENBLAS_NUM_THREADS=1 python3 make_diagnostics.py
```

The figure reads the named JSON outputs generated during this run. Its Matplotlib cache is confined to this directory.

## The free-fermion theorem to be generalized (proved; you may use it)
Majorana chain, n Majoranas per site, H = (i/4) Σ A_ab(x,y) γ_{x,a} γ_{y,b}, A real antisymmetric, nearest-neighbour
(A(x,y) = 0 unless |x−y| ≤ 1). Bloch matrix h(z) = i(A(0) + z A(1) − z^{-1} A(1)^T), z = e^{ik}. If every zero-energy
crossing is linear (CFT limit), then c_L = c_R and c = (number of zeros of det h(z) on |z| = 1, with multiplicity)/4.
Expanding det h(z) by columns, a term using s columns of zA(1) and t of z^{-1}A(1)^T vanishes unless s, t ≤ rank A(1),
so det h is a Laurent polynomial of degree ≤ rank A(1) in z and z^{-1}; hence c ≤ rank A(1)/2 ≤ n/2 = log_2 d. The same
holds for any period p (only one bond crosses a cell boundary, so the inter-cell rank is ≤ n), and for charge-
conserving fermions with n_c orbitals per site, c ≤ rank T_1 ≤ n_c = log_2 d. Interpretation: c counts chiral channels
through one bond, bounded by the rank of the coupling across that bond.
Interacting chains beat log_2 d (ULS at d = 3 has c = 2 > log_2 3, and the d = 4 states 0, up, down, updown of a
spinful fermion site can host SU(4)_1 with c = 3 > n_c = 2), so the interacting generalization must have a different
right-hand side, ideally d − 1, or an invariant that reduces to rank A(1)/2 in the quasi-free case.

## Task
Every site Hilbert space C^d can be written with partons: d complex fermions f_{x,a}, a = 1..d, with the
constraint Σ_a f^†_{x,a} f_{x,a} = 1 (one parton per site, a U(1) gauge constraint); more general parton
representations use n_c fermion orbitals with a larger gauge group G_g (e.g. spin-S via 2S flavours of spin-1/2
fermions with Sp/SO gauge groups, Majorana partons with SU(2) gauge structure). A free-parton mean-field state with
nearest-neighbour hopping/pairing has, by the theorem above, c_free ≤ (inter-site coupling rank) ≤ n_c. Projecting
or gauging should remove the gauge sector, and in 1+1D a gauged free-fermion CFT flows to the coset
U(n_c)_1 / G_g (or SO(2 n_c)_1 / G_g), with c = c_free − c(G_g at the induced level).
1. Make this precise as a theorem schema. State exactly which class of interacting chains it covers (chains whose IR
   equals the IR of a gauged nearest-neighbour free-parton theory), which steps are standard parton lore and which
   can be proved, and what "IR equals" must mean.
2. Prove that the minimal representation (n_c = d, U(1) constraint) gives c ≤ d − 1, with equality for the uniform
   one-parton-per-site Fermi sea (SU(d)_1, ULS). Then show, by enumerating parton representations, induced levels
   and conformal embeddings, whether ANY parton representation of C^d can yield c > d − 1. Key examples: spin-S
   chains (Takhtajan–Babujian SU(2)_{2S} via U(2S·2)_1 ⊃ SU(2)_{2S} × ...), Ising and Potts (Majorana or Z_N
   partons), t–J (d = 3, c = 2), Hubbard (d = 4, c = 2), SU(4)_1 on a spinful fermion site.
3. Find what replaces "rank of A(1)" in the parton setting (rank of the mean-field hopping across one bond, minus the
   gauge subtraction) and whether a bond-rank statement survives the gauge projection.
4. Identify the gap between "IR of a projected parton state" and "IR of an arbitrary nearest-neighbour H". Is there a
   variational or adiabatic argument (e.g. every critical NN chain is adiabatically connected to, or bounded by, some
   parton theory), or a counterexample class (CFTs that no NN parton construction reaches)? Locate the missing lemma.
## Deliverable

## Background (shared by all campaign specs; everything here is given, you may use it)

The c–d conjecture (J. I. Latorre and G. Sierra, arXiv:2403.17242, J. Stat. Mech. 2024, 113103).
A chain of L sites with Hilbert space (C^d)^{⊗L}, periodic boundary conditions, and
H_L = Σ_{i=1}^{L} h_{i,i+1}, where h is one fixed Hermitian d²×d² matrix acting on sites i, i+1
(so H is translation invariant by one site). If the low-energy spectrum of H_L is described by a
collection of unitary CFTs (possibly with different velocities) with central charges c_a, then
  c_T = Σ_a c_a ≤ d − 1.
Equality holds for the SU(d) Uimin–Lai–Sutherland (ULS) chain h = P (the swap), whose IR is SU(d)_1 with
c = d − 1. So the conjecture is equivalent to c_max(d) = d − 1. Longer-range chains reduce to NN ones by
blocking (a term spanning r+1 sites gives local dimension d^r).

Established facts (you may use them; do not re-derive):
1. c_L = c_R for such chains (Kapustin–Spodyneiko, PRL 123, 060601: no equilibrium energy current).
2. Quasi-free fermion NN chains (any period): c = (#zeros of det h(z) on |z|=1)/4 ≤ rank A(1)/2 ≤ log_2 d.
3. Entropic arguments cannot work: any monotone lattice c-function bounded by K log d at the lattice scale
   gives c ≤ K log d, false for SU(d)_1 at large d (block-entropy Casini–Huerta: K = 3, fails at d ≥ 7).
   Equivalently the conformal regime of the SU(d) chain starts only at l* ≳ (d−1)/(3 log d).
4. Thermodynamic / Lieb–Robinson / f-sum inequalities bound only c times a power of the conformal window:
   e.g. s = πcT/(3v) ≤ log d gives c T*/v ≤ (3/π) log d. ULS has ‖h‖ = 1 and spec(h) = {±1} for every d,
   so no bound in terms of ‖h‖, the Lieb–Robinson velocity, or the eigenvalues of h can exist.
5. LSM-type anomaly arguments give LOWER bounds c ≥ d − 1 in the SU(d)-fundamental and Z_d×Z_d classes.
6. WZW IR with on-site G acting on C^d via R: c(G_k) = k dim G/(k + h^∨). Gutzwiller partons give
   SU(d)_1 ⊃ G_{ind R} (ind = embedding index), so k ≤ ind(R) implies c ≤ d − 1 (GKO coset unitarity).
   For SU(N) fundamental, SO(N) vector, SU(2) spin 1, SU(N) antisymmetric², E6 27 the largest allowed k
   equals ind(R) (1, 2, 4, N−2, 6). Pure SU(2)_k needs no bound for spin ≥ 3/2.
7. Near misses (each drops one hypothesis): d = 2 with three-site terms reaches c = 3/2 (Rahmani–Zhu–Franz–
   Affleck interacting Majorana chain) and c = 2 (Σ S_j·S_{j+2}); SU(2)_k anyon chains violate c ≤ d_q − 1
   if d is read as the quantum dimension; Motzkin chains are not conformal; frustration-free gapless chains
   have gap O(1/L²), so they are never conformal.
8. Known saturating examples: SU(d)_1 (ULS), the qutrit XX chain (d=3, c=2), the t–J model (d=3, c=2).
   Lin–McGreevy exact single-site vector fixed points for d = 2 exist with c_Δ ∈ [1.13, 1.85] but none is
   scale consistent, so they say nothing about c_max.

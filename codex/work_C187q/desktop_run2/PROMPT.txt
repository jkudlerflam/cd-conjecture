What it is. This is a quick test of a candidate counterexample to c ≤ 1 for nearest-neighbour qubit chains. The test runs C173's effective model (hard-core particles with no two adjacent, NN hop w, NNN hop −1, interactions V2 and V3) with a blockade-exact, N-conserving DMRG (fibdmrg.py, which is validated, so do not modify it). There are 32 runs at density 1/12 (N = L/12), |w| = 1, phi = pi/2:
- fit8: couplings fitted from the full chain at V/Delta = 8 (V2 = −1.7334, V3 = −0.4930). There the opposite-valley pair is unbound.
- sw: the bare couplings (V2 = −2, V3 = −2/3). There the pair is bound, with binding 0.0195 and a size of about 21 sites.
- c1 and c2: known c = 1 and c = 2 controls.
The sizes are L = 48, 96, 144 and 192. Both fit8 and sw have N - 1 and N + 1 runs.

How to run it.
1. Copy the whole desktop_run folder to a local directory OUTSIDE Dropbox (for example ~/c187q_run). The runs write large checkpoint files to out/ckpt/, which must not sync through Dropbox.
2. Check that python3 has numpy and scipy. If anything is missing, ask me before installing.
3. In the local copy, run `bash run_desktop.sh` in the background. By default it uses half the cores, with 2 threads per task. Leave enough cores free that the machine stays usable. It runs the smallest sizes first.
4. While it runs, check progress now and then (tail logs/*.log). Run `python3 summarize.py` whenever new sizes finish.
5. Whenever a size finishes, and at the end, copy back into the Dropbox desktop_run folder:
   - out/*.jsonl, but NOT out/ckpt
   - logs/
   - the output of summarize.py, saved as summary.txt
   This lets my other Claude session read the results.

How to read the output. summarize.py prints two things.
- Two-size central-charge estimates c = 6 ΔS̄ / ln(L2/L1) for each family, over three cut windows. At these sizes the controls should read roughly 0.9 to 1.0 for c1 and 1.8 to 2.0 for c2. Judge fit8 against the controls, not against the ideal values.
  - If fit8 reads close to c2 and well above sw, that supports a real c = 2.
  - If fit8 reads close to c1 or sw, that argues against it.
- The parity gap E(N+1) + E(N−1) − 2E(N), for fit8 and for sw. This is the decisive output.
  - For sw, the gap should level off near the binding energy, about 0.02, so L × gap grows roughly linearly. That is pairing, c = 1.
  - For fit8, if L × gap stays roughly constant, the gap is closing like 1/L, which supports a two-component c = 2 gas.
  - If fit8 also levels off, it argues against.
  - At this low density the two-size entropy estimates are noisy, so weigh the parity gap more.
Also check the truncation error in the last sweep. Anything above about 1e-6 means that size is not converged, so say so.

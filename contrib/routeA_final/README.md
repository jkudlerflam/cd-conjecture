## Claim

Route A builds, for each n, a chain in which sites group spontaneously into cells, each cell carries an exactly degenerate code of n logical complex fermions with silent ports, and neighbouring cells interact only at second order, so that the low-energy theory is n non-resonant fermion bands (c = n). In the frozen version the cells break translation, which puts the chain outside the hypothesis of Latorre and Sierra on most rings (red team §5). This document assembles the mobile completions, in which one-site translation is unbroken.

Form V, one-vacancy completion, d = 24. Add one vacancy state to the 23-letter frozen bond h of `contrib/explicit_candidate/`, let it swap with any occupied letter, and let a weak copy of h act on occupied neighbours,

```
h_24 = −t Σ_{a=1}^{23} (|∅ a⟩⟨a ∅| + h.c.) + J h_occ − (μ/2)(n ⊗ 1 + 1 ⊗ n),      n = 1 − |∅⟩⟨∅|.
```

Claim: for each n, on every sufficiently long ring, the low-energy theory is one compact boson for the vacancy ("charge") fluid plus the n logical flavours of the squeezed internal chain, so c = n + 1. At n = 23 this is d = 24 and c = 24 > d − 1. This is the primary explicit claim against c ≤ d − 1.

Form W, wrapper completion. A positive frustration-free core inside the C8 selector and arrow wrapper, so that mobile cells of lengths n + 3 and n + 4 carry the same n modes and the cell lengths form a c = 1 fluid, on every ring with L ≥ (n + 3)(n + 4). Two cores are available. C39's two-bus 46-letter core (d0 = 96 · 46 + 48 = 4464) has its finite-dimensional band conditions proved for every n (C39, C42), so it is the route to unbounded c at fixed d; it beats c ≤ d0 − 1 itself only for n ≥ 4463. C32's 28-letter core (d0 = 2736) is the original design, with the same band conditions certified here for n ≤ 48; it would beat c ≤ d0 − 1 only for n ≥ 2735.

Unbounded c at fixed d excludes every bound c ≤ f(d). Form V at the single value n = 23 would refute c ≤ d − 1.

### 2.2 The core: 28 letters and every term

Letters, with on-site charge q (q_v = q_0 = 0, q_± = ±1, a ∈ {0, 1} the data bit, s the token species, v the vacuum token, 0, +, − excited):

| Letters | Count | Charge |
| :-- | --: | :-- |
| L_a, R_a (data left / right of the token) | 4 | a |
| d_{s,a}, s ∈ {v, 0, +, −} (token on the data rail) | 8 | a + q_s |
| x_{s,a}, s ∈ {0, +, −} (token on the express rail) | 6 | a + q_s |
| A_∅, B_∅ (empty left and right markers) | 2 | 0 |
| A_s, B_s, s ∈ {v, 0, +, −} (marker holding the token) | 8 | q_s |

A legal core is A, then n data sites, then B (k = n + 2 sites), with one token. Write z_s(a) = (−1)^a for s = 0 and 1 otherwise, φ for the neutral express phase and ψ_s for the loop phases. The moves, each with its reverse:

```
data rail     d_{s,a} R_b  ↔  L_a d_{s,b}         amplitude  −z_s(a)                     s = v,0,+,−
express rail  x_{s,a} R_b  ↔  L_a x_{s,b}         amplitude  −z_s(a) e^{iφ[s=0]}         s = 0,+,−
left link     A_s R_a      ↔  A_∅ d_{s,a}         amplitude  −1                          s = v,0,+,−
switch        A_σ d_{s,a}  ↔  A_σ x_{s,a}         amplitude  −1                          s = 0,+,−, any A_σ
vacuum right  d_{v,a} B_∅  ↔  L_a B_v             amplitude  −1
express right x_{s,a} B_∅  ↔  L_a B_s             amplitude  −z_s(a) e^{iφ[s=0]}         s = 0,+,−
loop link     d_{s,a} B_∅  ↔  L_a B_s             amplitude  −t_d z_s(a) e^{iψ_s}         s = 0,+,−
```

Each move c|v⟩⟨u| + h.c. enters as its positive edge matrix E(c; u, v) = |c|(|u⟩⟨u| + |v⟩⟨v|) + c|v⟩⟨u| + c̄|u⟩⟨v| (eigenvalues 0 and 2|c|). On-site terms: m on every excited-token letter, an extra D on A_s, B_s and x_{s,a} for excited s, and the number-conserving conversion g(|d_{+,0}⟩⟨d_{0,1}| + |d_{−,1}⟩⟨d_{0,0}| + h.c.). On-site terms are split half to each adjacent bond, with the endpoint halves in the boundary terms a_pay, b_pay. A penalty K sits on every pair whose arrows mismatch (L → L, R → R, d/x: L → R, A_∅ out L, A_s out R, B_∅ in R, B_s in L), on an A as right member or a B as left member of a bond, and, through a_pay and b_pay, on a first site that is not an A or a last site that is not a B. The core bond is s·h_core, with s the core energy scale.

The port, acting on (B letter of the left cell, A letter of the right cell):

```
V = F_0^B F_0^A + i F_+^B F_−^A − i F_−^B F_+^A,
F_0 = |0⟩⟨v| + |v⟩⟨0|,   F_+ = |+⟩⟨v| + |v⟩⟨−|,   F_− = F_+†      (on the species label of A or B)
```

[proved, C32 PROOFS §1] Every term conserves Q = Σ_sites q. Every move preserves outer arrows, so all penalty projectors commute with the core Hamiltonian. The complete legal sector has dimension (7n + 8)2ⁿ. Its zero space is the code

```
G|a_0…a_{n−1}⟩ = (n+2)^{−1/2} Σ_{j = A, d_0, …, d_{n−1}, B} |v at j; a⟩,    dimension 2ⁿ,
γ_core ≥ min(K, m − |g|, 2[1 − cos(π/(n+2))]).
```

Q is the logical fermion number on the code and e^{iπQ} its parity. V changes vacuum to excited species, so its compression onto the code vanishes.

This core is the 23-letter folded bus of `contrib/explicit_candidate/` §1.2 with three changes: a left marker A (five letters), positive edge matrices in place of bare hops, and no marker chemical potential, since length selection moves to the selector track.

V8. On M = bN occupied sites the selected marker patterns form b orthogonal offset subspaces, which R permutes cyclically, with R^b equal to the payload cell translation S = e^{iQ}. So R has eigenvalues e^{iθ_r}, θ_r = (Q + 2πr)/b, each fixing a charge boundary twist. Combined with the integer charge boost this is one charge-current lattice in steps of 1/b. The b "vacua" of the frozen internal chain are therefore twisted towers of a single charge boson, split at order v_c/(b²L), and the first marker harmonic e^{2πiy/b} = e^{2πiρx/b}e^{−2iφ_c/b} has dimension 1/b² but zero expectation: squeezed string order, algebraic physical order. V9. The grand-canonical ground state chooses M_b = b·round(ρ_*L/b). The rounding costs at most C_ρb²/(8L), while an internal wrong-length defect costs a fixed amount of order Jα(γ_b − 5B) at first order. Whether the defect cost survives at finite J (a vacancy can relieve an unfavourable internal bond) is assumption V11′.

V10. A neutral payload monomial z (dimension d_z) combined with marker harmonic m has w = (m + q_z/2π)/b, physical momentum 2πρw and free dimension w² + d_z. For 2/5 < ρ < 3/5 every ℓ ≠ 0 vertex is irrelevant, and the ℓ = 0 vertices with d_z = 1, 2 are the bilinear and quartic resonances that C33 and C37 exclude. ## 5. Order of limits

1. Fix n. Choose every coefficient in the order of Section 1.2 (Form V) or 2.4 (Form W). Every coupling, including λ, J/t (Form V), and u, w/U, s/δ (Form W), is a fixed nonzero number. None is sent to zero, and none depends on L.
2. Take L → ∞ over all ring lengths beyond a fixed threshold, L ≥ L_* for Form V (V9) and L ≥ (n + 3)(n + 4) for Form W (every such L admits a b/(b + 1) tiling, `selector_wrapper.md` §4). The central charge is read from the conformal towers or from the interval entanglement of the infinite chain, ((n + 1)/3) log ℓ, which does not depend on the velocities; the Casimir coefficient is velocity weighted, and at irrational density L(E_0 − eL) has no limit (referee of C44/C45, §4). At generic densities the zero-mode offsets move with L (C13 §7, C20 §5), as for an XXZ chain in a generic field, so the towers are those of one c = n + 1 theory in L-dependent charge and twist sectors, and along subsequences a neighbouring charge sector approaches the 1/L scale.
3. Then let n → ∞ along the sequence h_n, if unbounded c is wanted. Nothing is uniform in n. The conformal crossover energy goes to zero faster than any power of the bond norm, as it must: at fixed d the normalized bonds have convergent subsequences, and c-theorem reasoning (STATUS, "How the construction sits in parameter space") requires the limit to be gapless and non-conformal or to have a diverging crossover scale. The natural limits are the selector's dilute z = 2 threshold or a point with extensive degeneracy (`contrib/routeA_assembly/` §5).

Two interchanges are not allowed. Finite-cluster or finite-ring expansions (in λ, or in J against the charge level spacing) are not uniform in L, because the retained manifold has bandwidth growing with L and the charge fluid is gapless, so no global Schrieffer–Wolff argument gives the thermodynamic limit (C26 §8, `doping_check/` §3). That is the job of the local-elimination inputs W14 and V11. And the limits w/U → 0, s/δ → 0 that equalize Form W's two cell lengths are never taken; C32 bounds the mismatch at fixed small values chosen before λ.

## 7. What a referee is most likely to attack

1. "There is no measured counterexample." Correct. For Form V at n = 23 every finite-dimensional input is established, the infrared conclusion is a weak-coupling inference with inputs P and M (G1), and nothing with c > d − 1 has been measured. For Form W with C39's core the band inputs hold for every n, the wrapper is audited (G3) and the coupling hierarchy is closed under one standard input S (G4), so unbounded c at d0 = 4464 is a correct derivation conditional on S; it too is unmeasured, and beating c ≤ d0 − 1 with it needs n ≥ 4463, while C42's parameter search has been run only at n ≤ 3 and has no depth bound (referee of C39, item 3).
2. "The scales are absurd." At C33's n = 23 point the logical energies are near 10⁻⁴³³ in internal units, times λ², while the momentum margins are moderate (δ₂ > 0.014, δ₄ > 3.2 × 10⁻⁷); in Form V the vacancy fluid is faster than the internal logical modes by more than 400 decades, and C39's small-n certified points have D near 10¹⁰⁰ and g near 2^{−1000}. Our referee's estimates for the d = 24 chain at n = 23 are λ ≲ 10⁻²¹⁷ (about 10⁻⁴³⁵ if one stops at the second-order Bravyi–DiVincenzo–Loss remainder), J/t ≲ 10⁻⁸⁸⁰, slowest physical speed near 10⁻¹⁷⁴⁵ t and defect crossover length L* of order 10⁸⁸⁷ sites, so nothing at n = 23 will ever be checked numerically and the conclusion rests on asymptotic arguments. Existence at fixed n is still legitimate, because the conjecture concerns each fixed h and no step bounds a small scale from below by a larger one. Spin–charge separation is normally argued for J ≪ t, which holds here to an extreme. The specific worry is that weak-coupling stability is being applied across hundreds of decades with n separate crossover scales; C40's multiscale argument says the hierarchy enters only through finite matching constants and the length of the marginal flow, but nobody has computed those constants.
3. "The thermodynamic limit is not controlled." A global Schrieffer–Wolff is impossible (the code band is extensive, the vacancy fluid gapless), and finite-ring expansions are not uniform in L. What is proved instead is a fixed-order local Schrieffer–Wolff transformation with a volume-independent remainder (Bravyi–DiVincenzo–Loss for the blocked frozen cells; C45 explicitly, with constants, for the wrapped chain) and a massive threshold for the transformed reference. The last step, stability of a Gaussian phase with tiny velocities against a small quasi-local remainder (C45's S), is a standard input, not a theorem, and here it carries the whole thermodynamic claim. A literature check (`contrib/lit_ir_step/`) finds no published theorem covering integrate-out-then-bosonize at fixed coupling in the thermodynamic limit: rigorous tools control energy densities, finite times or gapped targets, and physics checks of the step reach four flavours and two velocity scales, not many flavours with hierarchical velocities. Astra C46 attempted the missing imaginary-time decoupling theorem and did not close it; it proves a thermal reference comparison and the Gaussian reference's free energy, and shows that the raw Grassmann expansion must be resummed (G4). C45 notes that comparing an extensive error with 1/L is the wrong criterion; Gaussian corrections renormalize velocities by a small fixed fraction and irrelevant ones vanish relative to the 1/L spacing.
4. "This is not a CFT in the strict sense." Translation is unbroken and the spectrum is n + 1 bosons with different velocities in L-dependent zero-mode sectors. Latorre and Sierra allow a collection of unitary CFTs with different speeds, and they do not require exact uniqueness on every finite ring (`doping_check/CONJECTURE_SCOPE.md`). A referee who requires one fixed vacuum sector along every L would also reject the XXZ chain in a generic field. Every-ring uniqueness is nevertheless listed as gap G2, since it is not proved for these complex bonds.
5. "Hidden order and blocking." Blocking b sites raises d to d^b, which is the right objection to the frozen chain (red team §5). In Form V the period-24 order lives only in squeezed (material) coordinates; it is neither a broken physical symmetry nor a degeneracy, and appears as the charge quantum b of the compactification, with algebraic physical marker correlations of exponent 2/b². A referee may still ask whether "d = 24" is honest when the material cell is a 23²⁴-dimensional object. The answer is that the bond is one 576 × 576 matrix repeated on every bond, which is all the conjecture fixes. Our referee adds two points that the synthesis does not state: only 24-particle composites are gapless (a "charge-24" liquid), and the charge fluid re-imprints the cell period on the payload at relative order J/t, harmless only because the payload's own unit cell is the material cell.
6. "Is the density window fine-tuned?" The window 2/5 < ρ < 3/5 is open, and the campaign works at ρ = 1/2 where K_gap = 4 makes every gap harmonic dimension at least four; exact half filling is not needed (referee §2), only the free-charge threshold theorem uses it. Outside the window there are uniform low-dimension marker harmonics, for example at ρ = b/(b + 1) (C41 §5); in the d = 11 demonstrator lift the analogous resonance at ρ = 3/4 has dimension 16K/9 and locks a period-4 crystal (`vacancy_mobile_numerics/`). So the vacancy density is a real tuning parameter, set by μ.
7. "Is the logical chain really Gaussian, and is T what you say?" At order g² the bond is an exact fermion bilinear plus a scalar, and the non-Gaussian part starts at g⁴ and is bounded in operator norm. C33 and C37 check the frozen coefficient against literal cells to 10⁻¹²; C39/C42 check theirs by direct source contraction; the mobile-core coefficient used here matches a literal extraction to 10⁻¹⁶.
8. "Which Hamiltonian, exactly?" For Form V, t, J, μ and the final λ are never given numerically; what is defined is a family "for sufficiently small couplings" with uncomputed matching constants (referee problem 3; C41 reports no justified interval for J/t). Existence at fixed n needs no more, but a referee may ask for one explicit member. Our referee also notes that the campaign's synthesis relabels the matching input M, which its own infrared report tags as assumed, as "controlled"; this document keeps it as assumed (V11).
9. "Who checked this?" Every proof is by Astra (gpt-6-astra), by GPT-6-family workers of the collaborator's campaign, or by Claude agents, cross-checked only by other AI runs (red team, C33 audit and rerun, margins audit, referees of C39 and of the d = 24 chain, squeezing checks).

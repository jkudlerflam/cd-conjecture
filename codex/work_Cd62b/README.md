# Cd62b: the cell velocity budget at all orders

One run of `gpt-6.2-astra` at effort max, 2026-11-19, asked to prove or break the velocity budget of `codex/work_Cd62` (REPORT §9.210) beyond second order: order-k ranks, long cells, interactions, the step from the effective model to the chain, and the d = 9 frozen chain as a test case. The brief is `TASK.md`. Its inputs were `codex/work_Cd62/PROOF.md` and `RESULT.md`, REPORT §9.93, §9.98, §9.207 and §9.210, the specs `_Cd_target.md` and `_bound_background.md`, and the d = 9 notes, README and `bond9.py` from `contrib/markerless_d9_d10/`. The outcome is neither a proof nor a disproof. Summary and context are in REPORT §9.211.

- `RESULT.md`, `PROOF.md`, `PROGRESS.md`: the run's own output, unedited. `PROOF.md` (about 9000 words) has not been checked line by line.
- `check_d9.py`: the run's nine-letter check. Run `python3 -B check_d9.py` (or `python3 -B check_d9.py 135` for the second precision). Standard library only.
- `check_resolvent.py`: exact rational checks of the connected energy through sixth order and of the gate Gram matrix. Run `python3 -B check_resolvent.py`. Standard library only. Rerun by the coordinator, output as stated.
- `claude_check/fermi_velocities_n9.py`: the coordinator's independent check of the run's d = 9 velocity finding, from the repository's own `full_loop_whitened_n9.npz` with the velocity formula of `full_loop_integer.py`. Run from the repository root, `python3 codex/work_Cd62b/claude_check/fermi_velocities_n9.py` (numpy and scipy). It prints the 18 Fermi velocities, the eigenvalues of the Hermitian part of the hopping in the same units, the slopes in the whitened frame and the weight of each zero mode on the two deepest orbitals, and asserts that the slowest velocity equals the certificate's `log10_min_speed_normalized` and that all velocities lie between the two smallest hopping eigenvalues.

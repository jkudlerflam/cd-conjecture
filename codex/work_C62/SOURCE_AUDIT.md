# C62 source audit

2026-10-28. Primary sources were opened using the browsing tool. No shell downloads or network commands were used. No author was contacted.

## Reference definitions

[read] [Benfatto and Mastropietro, 0907.2837](https://arxiv.org/pdf/0907.2837), equations (29)-(33), defines a Grassmann reference with a spacetime-smoothed interaction. Lemma 2.1 matches infrared correlations. Equations (52), (135)-(139) distinguish its coupling from the Hamiltonian Luttinger convention. These passages support the reference distinction and the parameter inputs used in PROOF Section 2. They do not identify a thermal vacuum scalar. The zero-temperature flow discussion (81)-(95) was also inspected, consistently with the C57/C59 audits.

[read] [Benfatto, Falco and Mastropietro, 1303.3684](https://arxiv.org/pdf/1303.3684), Section 2.1, expressly calls its effective model non-Hamiltonian. This is a separate spinful model; it is cited only to clarify the reference convention, not applied as an XXZ theorem.

[read] [Langmann, Lebowitz, Mastropietro and Moosavi, 1511.01884](https://arxiv.org/pdf/1511.01884), Section 3, gives the filled-sea Fock representation, current commutators, unitary diagonalization and complete charged oscillator eigenstates. Appendix B treats general forward interactions. This is the imported operator representation in PROOF Section 3. The new finite-window trace argument is proved there rather than attributed to a thermal XXZ theorem. [1701.06620](https://arxiv.org/pdf/1701.06620) was also inspected for the finite-temperature Hamiltonian convention; no additional theorem from it is needed.

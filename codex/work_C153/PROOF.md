# C153 derivations: the staggered-charge box

Tags: [proved] means a complete argument at the level of rigor of the cited exact results; [derived] means a standard physics derivation (bosonization, perturbation theory, Luttinger-liquid relations) with its assumptions stated; [numerical] means calibrated numerics with sizes given; [heuristic] means a plausibility argument; [assumed] marks inputs taken from the literature without re-derivation.

## 0. Model, frames, symmetries

Original frame, Pauli matrices, a = 1, b > 0:

    H = sum_j [ X_j X_{j+1} - Y_j Y_{j+1} + u Z_j Z_{j+1} + b Z_j ],    r := sqrt(1 + b^2/4).        (0.1)

Rotated frame (pi rotation about x on odd sites, a product unitary on even rings, so spectra and every bipartite entropy are unchanged):

    H' = sum_j [ X_j X_{j+1} + Y_j Y_{j+1} - u Z_j Z_{j+1} ] + b sum_j (-1)^j Z_j.                    (0.2)

In spin-1/2 language (S = sigma/2) this is the XXZ chain J sum (S^x S^x + S^y S^y + Delta S^z S^z) with J = 4, Delta = -u, in a staggered field h_s = 2b. The staggered charge Q = sum_j (-1)^j Z_j of (0.1) becomes Q = sum_j Z_j = 2 S^z_tot of (0.2).

[proved] Symmetries of (0.2) on even rings: U(1) generated by Q; the generalized translation G = T o prod_j X_j (one-site translation times global pi rotation about x), with G Q G^{-1} = -Q; site reflection about a bond combined with the same flip; complex conjugation (H' is real). In the original frame G is the plain translation T. The one-site translation of the rotated frame alone is not a symmetry for b != 0, and its square T^2 is.

## 1. Exact inputs (cited, with what each one gives)

1. [proved, staggered_slice.md] For u > r: twofold Neel ground space (original frame), energy -uL, exact gap 4(u - r). Gapped, c = 0.
2. [proved, staggered_slice.md and C15 section 2.4] At u = r: H + rL is a sum of rank-one positive bond projectors 4r|v><v|; the ring ground space has dimension exactly L + 1, one state per Q-sector; the one-defect branch over the Neel state is E_-(k) = 4r - 4 sqrt(r^2 - sin^2(k/2)) = (k^2)/(2r) + O(k^4) (cell momentum k). Not a finite-velocity CFT.
3. [proved, rank_one.md, Suzuki-Fisher] For u <= -1 and b != 0: unique ground state and gap >= 2|b|. Gapped.
4. [proved] u = 0: quadratic under Jordan-Wigner, quasiparticle energies sqrt(4b^2 + 16 sin^2 p) >= 2b. Gapped.
5. [assumed, Bethe ansatz] b = 0 (outside the box but its edge): XXZ with Delta = -u, gapless c = 1 for -1 <= u < 1 with K = pi / (2 arccos u) (convention K = 1 for free fermions, K = 1/2 at the SU(2) antiferromagnet), v = 2 pi sin(gamma)/gamma with cos(gamma) = -u.

The identity used below is (staggered_slice.md eq. (4)), exact for every u:

    H + uL = K_* + (u - r) D_L,   K_* = H(u = r) + rL >= 0,   D_L = sum_j (1 + Z_j Z_{j+1}).        (1.1)

In the rotated frame D_L = sum_j (1 - Z_j Z_{j+1}) = 2 x (number of unequal neighbouring pairs).

## 2. Small b: bosonization of the staggered field

[derived, standard] Bosonize (0.2) around the b = 0 Luttinger liquid. With rho(x) = -(1/pi) d phi and the convention above,

    S^z_j = -(1/pi) d_x phi + (-1)^j A_z cos(2 phi) + ...,
    H = (v/2pi) int [ K (d_x theta)^2 + K^{-1} (d_x phi)^2 ] + (h_s A_z / a) int cos(2 phi) - g_u int cos(4 phi).   (2.1)

The staggered field couples to the Neel component cos(2 phi), scaling dimension K. The umklapp cos(4 phi) has dimension 4K. With K = pi/(2 arccos u):

- K < 2, i.e. u < cos(pi/4) = 1/sqrt(2): cos(2 phi) is relevant. phi is pinned at a single minimum per period (the compactification is phi ~ phi + pi, and cos(2 phi) has one minimum in that period), so the ground state is unique and gapped, with gap scaling Delta ~ b^{1/(2 - K)}. The pinned state is the rotated-frame Neel state aligned with the field, i.e. the original-frame polarized state dressed by pair fluctuations. Near u = -1 (K -> 1/2) this is the familiar b^{2/3} (times logarithms) gap of the Heisenberg antiferromagnet in a staggered field.
- K > 2, i.e. 1/sqrt(2) < u < 1: cos(2 phi) is irrelevant. The Luttinger liquid survives with c = 1 and a renormalized K.
- K = 2: marginal. The flow is of Kosterlitz-Thouless type, dK/dl = -C y^2, dy/dl = (2 - K) y, with y proportional to b. Its separatrix is K_0 - 2 = C' |y|, so the phase boundary leaves the b = 0 axis linearly,

      u_BKT(b) = 1/sqrt(2) + kappa b + O(b^2),   kappa > 0.                                        (2.2)

  The coefficient kappa needs the Lukyanov amplitude A_z at Delta = -1/sqrt(2) and the normalization of C'; it is not computed here. [numerical] The DMRG data of contrib/d2_staggered and the ED of section 7 give kappa of about 0.25 for b <= 1.

[derived] Translation acts as phi -> phi + pi/2 and the spin flip as phi -> -phi, so G: phi -> -phi + pi/2 leaves (2.1) invariant. No other vertex operator of dimension below 4K is allowed by U(1) x G. In particular there is no relevant operator that could open a gap at K > 2, since the next candidate, cos(4 phi), has dimension 4K > 8.

[derived] Consequence for c at small b: inside the liquid the infrared theory is the b = 0 compact boson perturbed only by irrelevant operators, so c = 1. The b = 0 XXZ chain has no low-energy degree of freedom besides this boson, so a weak staggered field has nothing else to make critical. Both statements are perturbative in b at fixed u.

## 3. The factorization line and the first-order expansion below it

### 3.1 The kernel states as projected product measures [proved]

In the rotated frame, write bit s_j = 1 for Z_j = -1. The proof of the (L+1)-fold kernel in staggered_slice.md applies the invertible filter F = diag(B, -A) on every even site and finds that F psi must be symmetric under all neighbouring swaps. Hence the kernel state with n ones is

    psi_n = F^{-1} |Dicke_n>,   psi_n(s) proportional to prod_{j even} g(s_j),   g(0) = 1/B, g(1) = -1/A,   (3.1)

with A^2 = (2r + b)/(4r), B^2 = (2r - b)/(4r). Thus |psi_n(s)|^2 is the product measure in which an even site carries relative weight beta = B^2/A^2 = (2r - b)/(2r + b) for s = 1 against 1 for s = 0, odd sites carry equal weights, all conditioned on sum_j s_j = n. Write s = sqrt(beta). The identity used repeatedly below is

    s + 1/s = 4r / sqrt((2r - b)(2r + b)) = 4r / sqrt(4r^2 - b^2) = 2r,                          (3.2)

because 4r^2 - b^2 = 4.

By equivalence of ensembles for independent sites (local central limit theorem), local expectations in psi_n converge to those of the grand-canonical product measure with fugacity z fixed by the density rho = n/L, with O(1/L) corrections:

    p_e = beta z/(1 + beta z),   p_o = z/(1 + z),   rho = (p_e + p_o)/2.                           (3.3)

### 3.2 First-order energies [proved at first order in u - r]

Since D_L commutes with Q and each Q-sector contains exactly one kernel state, first-order degenerate perturbation theory in (1.1) has no mixing:

    E_n(u) + uL = (u - r) <psi_n| D_L |psi_n> + O((u - r)^2),
    <D_L>/L -> 2 f(rho),   f = p_e (1 - p_o) + p_o (1 - p_e).                                     (3.4)

f(rho) is the probability that a bond is unequal. In terms of x = ln z - ln(1/s), p_e = sigma(x + ln s), p_o = sigma(x - ln s) with sigma the logistic function. At x = 0 one has p_e = p := s/(1 + s), p_o = 1 - p, rho = 1/2 (Q = 0). Using sigma' = sigma(1 - sigma) and w := p(1 - p) = s/(1 + s)^2:

    d rho/dx = w,  d^2 rho/dx^2 = 0,  df/dx = 0,
    d^2 f/dx^2 = -2 w [ (1 - 2p)^2 + 2w ] = -2 w f_0,   f_0 := p^2 + (1 - p)^2 = (1 + s^2)/(1 + s)^2,

so

    d^2 f / d rho^2 |_{rho = 1/2} = -2 f_0 / w = -2 (s + 1/s) = -4 r.                              (3.5)

f has a single interior maximum (as a function of z, f = (1 + beta) z / ((1 + beta z)(1 + z)) is unimodal with maximum at z = 1/s, and rho(z) is monotone). With m = S^z density = 1/2 - rho, the energy density in the Q-sector of density m is, for u < r,

    e(m) = -u - 2 (r - u) f(m) + O((r - u)^2),     e''(0) = 8 r (r - u).                             (3.6)

So for u slightly below r the ground state lies in Q = 0 and the system is compressible with charge curvature 8r(r - u). [check, b = 0] f = 2 rho (1 - rho), e'' = 8(1 - u), which is the curvature of the XXZ chain near its ferromagnetic point (see 3.4). [check, numerical, dsk.out] 2L [E(N0 + 1) - E(N0)]/(r - u) at r - u = 1e-5 and L = 8 to 20 extrapolates in 1/L to 8r within one percent at b = 0, 0.5, 1, 2 (8.0, 8.25, 8.9, 11.0 against 8, 8.25, 8.94, 11.31; the b = 2 extrapolation is the roughest). At b = 4 and 8 the finite-size corrections are larger (22.4 at L = 20 against 17.9 at b = 4), consistent with a length scale growing with b (section 5).

[check] The Q = 0 energy at first order is -u - 2(r - u) r/(1 + r), since f_0 = 2rs/(1 + s)^2 = r/(1 + r). At (u, b) = (1.4042, 2) this gives -1.415916; the classical canted state of lswt.py gives -1.415936, the difference being O((r - u)^2).

### 3.3 Stiffness: the diamagnetic value and its quantum reduction

Twist the U(1) by phi across the ring (phase e^{i phi/L} on every sigma^+_j sigma^-_{j+1} of (0.2), gauge equivalent to one twisted bond). Define D_s by E_0(phi) - E_0(0) = D_s phi^2/(2L). Second-order perturbation theory in phi gives

    D_s = D_dia - D_para,   D_dia = -<X_j X_{j+1} + Y_j Y_{j+1}>,   D_para = (2/L) sum_n |<n|J|0>|^2/(E_n - E_0) >= 0,   (3.7)

with J the total current. [proved] In the Q = 0 kernel state at u = r the bond expectation follows from (3.3): the grand-canonical product state has <X_e> = -2 sqrt(p_e(1 - p_e)) and <X_o> = +2 sqrt(p_o(1 - p_o)) (the sign of g(1)/g(0) on even sites), and U(1) averaging splits the product equally between XX and YY, so

    D_dia = 4 sqrt(p_e (1 - p_e) p_o (1 - p_o)) = 4 w = 4 s/(1 + s)^2 = 4/(s + 2 + 1/s) = 2/(1 + r) =: D_cl.   (3.8)

This is also the classical (spin-wave) stiffness sin(theta_A) sin(theta_B) of the canted state, which explains why classical and kernel values coincide. Hence

    D_s(b) <= 2/(1 + r)   at u = r, Q = 0.                                                      (3.9)

[check] D_cl reproduces the exact one-defect mass of item 2 of section 1 near full polarization: along the classical degenerate family near the ferromagnet, theta_B/theta_A = r - b/2 =: kappa', and with flipped density n = (theta_A^2 + theta_B^2)/8 one finds D = theta_A theta_B = 8 kappa' n/(1 + kappa'^2) = 4n/r, while a dilute gas of quadratic particles with E = 2q^2/r (per-site momentum q, from (k^2)/(2r) with k = 2q) has D = n/M = 4n/r. They agree.

[numerical, dsk.out] At u = r and Q = 0, D_s(L) from the twist curvature (phi = 0.02):

| 0 | 1.000 | 1.143, 1.091, 1.067, 1.053 | 1.00 |

At b = 0 the paramagnetic term vanishes as L grows (SU(2) ferromagnet). For b > 0 it is a finite fraction of D_cl that grows with b. D_s stays positive at every b tested. [heuristic] Positivity for every finite b: at u = r the Q = 0 state is the U(1) projection of a product state with <sigma^+> != 0, so it has off-diagonal long-range order, and the exact defect branch has a finite mass; a vanishing stiffness would require the paramagnetic sum to cancel the diamagnetic term exactly, for which there is no mechanism.

### 3.4 The Luttinger liquid below the line [derived]

For a single compact boson, e'' = pi v/K and D_s = v K/pi, so v = sqrt(e'' D_s) and K = pi sqrt(D_s/e''). Inserting (3.6):

    K(u, b) = pi sqrt( D_s(b) / (8 r (r - u)) ) [1 + O(r - u)],    v = sqrt( 8 r (r - u) D_s(b) ) [1 + O(r - u)],   (3.10)

and with the diamagnetic bound (3.9),

    K <= K_0 := (pi/2) / sqrt( r (1 + r)(r - u) ),    v <= v_0 := 4 sqrt( r (r - u)/(1 + r) )   (to leading order).   (3.11)

[check, b = 0] K_0 = (pi/2)/sqrt(2(1 - u)) and v_0 = 2 sqrt(2) sqrt(1 - u). The exact XXZ values are K = pi/(2 arccos u) and v = 2 pi sin(gamma)/gamma with gamma = pi - arccos u; with arccos u = sqrt(2(1 - u)) (1 + O(1 - u)) both agree at leading order. [check, numerical, kcheck.out] Ring ED K(L = 20) against K_0: 23.8 against 24.3 at (b, r - u) = (0.5, 0.002); 21.3 against 22.8 at (1, 0.002); 15.3 against 19.0 at (2, 0.002). The ratios are those predicted by sqrt(D_s/D_cl) and the finite-size e'' (for example b = 1: sqrt(0.883/0.944) sqrt(8.94/9.55) = 0.936 against 21.33/22.83 = 0.934).

[derived] Consequence. K diverges as (r - u)^{-1/2} at every fixed b > 0 (given D_s(b) > 0). The only symmetry-allowed vertex that can gap the boson, cos(2 phi), has dimension K and becomes ever more irrelevant; its bare fugacity is finite at fixed b, while the KT separatrix requires K_0 - 2 of order the fugacity. Hence there is an open gapless strip

    u_BKT(b) < u < r(b)   for every b > 0,                                                      (3.12)

with u_BKT(b) >= u_0(b), where u_0 solves pi sqrt(D_s/(8 r (r - u_0))) = 2 (the vortex renormalization only lowers K, so K_bare > 2 is necessary). With the diamagnetic value, r - u_0 <= pi^2/(16 r (1 + r)).

## 4. Spin waves and the classical phase diagram [derived]

lswt.py minimizes the classical energy of (0.2) for unit vectors on two sublattices and computes linear spin waves (Holstein-Primakoff, 4 x 4 bosonic Bogoliubov problem per cell momentum). Classical phases:

- rotated Neel (original polarized) for u < b/2 - 1: stable iff b/2 - u > 1 (the quadratic form (1/2)(b/2 - u)(alpha^2 + theta_B^2) - alpha theta_B is positive);
- canted in-plane antiferromagnet with a staggered z moment for b/2 - 1 < u < r;
- z ferromagnet (original Neel) for u > r: stable iff (u - b/2)(u + b/2) > 1, i.e. u > r. The classical boundary coincides with the exact one, as expected for a factorization line.

In the canted phase the spectrum has one Goldstone branch with velocity sqrt(e''_cl D_cl), equal to v_0 of (3.11) near u = r (b = 1, r - u = 0.01: 0.291 against 0.2906), and one optical branch whose minimum is 4.0 at every canted point computed (b = 0 to 8, lswt.out). Classically there is a single soft mode. The quantum lower edge of the liquid is the BKT line, far above the classical edge b/2 - 1 (at b = 0, 1/sqrt(2) against -1), because vortices of the in-plane angle are where cos(2 phi) comes from and spin waves do not see them.

## 5. Large b: two species and their conversion [derived at second order; heuristic beyond]

[derived, C15 sections 2.3 and 2.4 translated] With n_j = (1 + Z_j)/2 in the original frame, (0.1) is H = 4u sum n_j n_{j+1} + (2b - 4u) N + 2 sum (sigma^+_j sigma^+_{j+1} + h.c.) + const. At large b the relevant region is u near b/2, where particles cost little and adjacent pairs cost about 2b. The second-order effective model on configurations without adjacent particles has energy unit t_2 = delta^2/V = 1/u (delta = 2, V = 4u); a particle hops by two sites, so particles on even sites (species e) and on odd sites (species o) are separately conserved at this order. The threshold of C15, m = 2 with m = (4u - 2b) u, sits at u = (b + sqrt(b^2 + 8))/4 = b/2 + 1/b + O(b^{-3}), in agreement with r = b/2 + 1/b + O(b^{-3}). Exactly there the one-sublattice sectors are degenerate (a ferromagnetic t-V chain at threshold on each sublattice) and the mixed configurations cost energy (C15 eq. (11)): the two species are immiscible. At third order a pair (e, o) is created or annihilated with amplitude of order delta^3/V^2 (C15: 2 delta^3/(3 V^2) on an isolated interval). Only Q = N_e - N_o is exact.

[derived] Matching with section 3. In the Q = 0 kernel state at u = r both species are present at density p = s/(1 + s) = 1/b + O(b^{-2}) per site (equation (3.3) with s = 1/b + O(b^{-3})). The defect mass is M = r/4 (one-defect branch), so the dilute kinetic energy scale per site is p^3/M of order b^{-4}, while the charge curvature is e'' = 8r(r - u), about 4b(r - u). The ratio of interaction to kinetic scales (a Lieb-Liniger-type parameter) is

    gamma ~ M e''/p ~ b^3 (r - u)/2.                                                            (5.1)

[heuristic] At large b the liquid is therefore controlled by the single scaling variable b^3 (r - u), and the BKT edge should sit at r - u_BKT ~ C/b^3. The available BKT estimates (r - u_BKT of about 0.05 at b = 2 and 0.010 at b = 4 from contrib/d2_staggered; section 7 for b = 6, 8) give b^3 (r - u_BKT) of about 0.4 and 0.6, consistent with slow approach to a constant. The first-order formula (3.10) is accurate only for gamma small, which explains why ED K at b = 4 falls below (3.10) already at r - u = 0.01 (gamma of about 0.3).

[heuristic] Why no second mode at large b. Write the low-energy theory as two dilute bosonic species with phases theta_e, theta_o and densities rho_e, rho_o. The conversion term lambda (psi_e^dagger psi_o^dagger + h.c.) depends on theta_+ = theta_e + theta_o and pins it once relevant, which gaps the total-density (+) mode and leaves the Q-carrying relative mode theta_- gapless. Its scaling dimension is (1/4)(1/K_e + 1/K_o) in a decoupled two-component bosonization, at most of order 1 for dilute species with K of order 1 or larger (it is smaller still near the ferromagnetic threshold, where K_e, K_o are large). It would be irrelevant only for K_+ below 1/4, which needs repulsion much stronger than hard core between the species. A useful alternative picture: in one dimension the hard-core e-o repulsion makes the species mutually impenetrable, so the total density behaves like a fermionized Tonks gas (K_c near 1) and the species sequence like a spin chain carrying Q; conversion is then a pairing operator of dimension about 1/(2 K_c) in the charge sector times an order-one spin factor, relevant. Either way the (+) sector is gapped and c = 1. The gap of the (+) sector and the liquid scale both come from the same order (lambda p and p^3/M, both of order b^{-4} with lambda of order b^{-2}), so there is no parametric separation that could create a long c = 2 crossover; the crossover length is a few interparticle spacings, of order b sites.

The second-order picture also explains why the liquid strip closes faster than 1/b: at second order (lambda = 0) the Q = 0 sector is the empty vacuum for m < 2 and phase separates into the one-sublattice (Neel) states for m > 2, so the liquid exists only through the conversion and the fine structure of the threshold.

## 6. The central charge in the box

### 6.1 The phase diagram

Combining sections 1 to 5, for b > 0 and -1 < u < r(b):

- P, the polarized phase, -1 < u < u_BKT(b): unique gapped ground state, adiabatically connected to the polarized product state at large b and to the pinned XXZ boson at small b (the two descriptions are the same state, the rotated-frame Neel order along the field). c = 0. Contains the exact free line u = 0 (item 4 of section 1) and borders the Suzuki-Fisher region u <= -1 (item 3). [derived; proved on u = 0]
- G, the liquid, u_BKT(b) < u < r(b): one compact boson for the staggered charge, ground state in Q = 0, K in (2, infinity), K -> infinity and v -> 0 as u -> r, given by (3.10) near the line. c = 1. [derived]
- The BKT line u = u_BKT(b): c = 1 with K = 2 and a marginal cos(2 phi) (logarithmic corrections). It starts at u = 1/sqrt(2) at b = 0 with slope kappa of about 0.25 and approaches u = r as r - u_BKT ~ C b^{-3} at large b. [derived at small b; heuristic and numerical at large b]
- The line u = r: L + 1 ground states, z = 2. Not a CFT. [proved]
- N, u > r (outside the box): Neel, gapped. [proved]

### 6.2 c <= 1, and the single-boson structure

The central question is whether a second sector, neutral or charged, can become critical somewhere in G or on its boundary.

(a) [proved] Any gapless point with nonzero compressibility for Q carries at least one boson for Q; since Q is exact and the ground state is in a single Q-sector, the Q-sector cannot split into two independently conserved currents unless an emergent second U(1) appears.

(b) [derived] Small b (section 2): the infrared theory is the XXZ boson plus irrelevant operators. Nothing else exists to become critical. c = 1 on G near b = 0 and c = 1 on the BKT line near b = 0.

(c) [derived] Near u = r (section 3): the unperturbed problem has a one-parameter (L + 1)-dimensional kernel, one state per Q, so the zero modes form a single U(1) family. The splitting (u - r) D_L acts within that family with a unique smooth minimum at Q = 0. The low-energy excitations at u = r form one quadratic branch; [numerical, boundary_spec.out] ring ED at u = r shows the lowest Sz = 0 excitation at L^2 (E - E0) equal to the exact one-defect value (b = 1, L = 16: 68.99 against 69.15), with the higher levels following the same pattern as the SU(2) ferromagnet at b = 0 and no additional level scaling like L^{-2} below the multi-defect states. A second gapless sector would need its own soft modes at u = r, and there are none. Spin waves (section 4) give one Goldstone and one optical branch with a gap of order one.

(d) [heuristic] Large b (section 5): the only candidate second mode is the total-density mode of the two species, and the conversion term that exists at third order pins it.

(e) [derived] Symmetry. A neutral Ising sector would need a Z2 order parameter outside the boson. The discrete symmetries are G, reflection and complex conjugation. Their order parameters built from the boson (dimerization sin(2 phi), Neel cos(2 phi), cos(4 phi)) are vertex operators of dimension K or 4K > 2 in G, so none orders and none produces an Ising line. An independent Ising line would have to come from the optical/(+) sector closing its gap on a codimension-one curve inside G.

(f) [numerical, sections 7 and 8] No such curve was found: ring ED neutral spectra show only the boson tower, and DMRG/FES (contrib/d2_staggered, b <= 4) give c between 0.95 and 1.05 wherever critical. Section 7 adds b = 6, 8 and the grid.

Conclusion: c <= 1 at every gapless point of the box, at the theoretical-physics standard in the three controlled corners (small b, u -> r, large b at the heuristic level) and numerically in between.

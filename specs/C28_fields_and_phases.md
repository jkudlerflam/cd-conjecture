# C28: Independent flavour fields and hopping phases at fixed alphabet (route A, gap G1)

Read `../../specs/_routeA_background.md`, `../../contrib/routeA_assembly/README.md` §7, `../work_C21/RESULT.md` and `../work_C21/LOCAL_CURSOR.md`, `../work_C22/RESULT.md`, `../work_C25/RESULT.md` and `../work_C26/RESULT.md` first. If `PROGRESS.md` exists in your folder, continue from it.

**Where things stand.** Two fixed-alphabet cells now exist. C21's 16-state cell has an exactly degenerate 2^n code, exact parity, a nonscalar source resolvent and exactly Gaussian second-order exchange of hopping rank 2n, but its hopping matrix has the form J = −2 R G_f (a reversal times a positive matrix), so at zero field its Fermi points sit only at 0 or π and the one-flavour chain is gapped. C22's computation-free 17-state cell has an exact code, parity, vanishing first order and enough poles, but its n = 2 second-order hopping matrix is gapped and a uniform flux does not give independent phases. The stable target needs n flavours with distinct Fermi momenta and either an exact U(1) (which forbids pairing) or displaced Fermi-sea centres (complex hopping phases that break the k → −k symmetry), with Sidon-type detuning (C26). C25 shows the composition with the mobile wrapper is controllable and that the proposed interface keeps the code frustration-free.

**Your task.** Supply the missing ingredient with a fixed alphabet, or prove it cannot be supplied this way.
1. Independent chemical potentials: add local terms (for example the coloured density readouts of C8, `../work_C8/RESULT.md`, or diagonal two-site operators that compress to logical Z_f fields) that give each flavour its own field, keeping the code exactly degenerate up to these fields and frustration-free where the wrapper needs it.
2. Breaking the reversal: find a local, translation-invariant way to make the second-order hopping complex with flavour-dependent phases (an oriented cursor, a chiral internal loop with flux, a directed clock), or else build the cell with an exact total U(1) so that pairing is forbidden and the Fermi points can stay at ±k_a. If you take the U(1) route, work out at one loop whether inter-flavour pair tunnelling (zero momentum for symmetric Fermi points) is irrelevant for the interactions the cell actually generates, and what fixes its sign.
3. Verify by exact diagonalization of two and three cells at n = 1, 2 that the effective chain has the intended hopping, phases and fields, with residual scaling as λ³, and compute the generated pairing and pair-tunnelling coefficients.
4. If it works, give the alphabet and d0 (frozen and mobile), and write the effective logical chain at n = 2 so a numerics agent can measure c. If it fails, state the obstruction precisely and whether it kills route A or only these cells.

## Where things stand

The bound L(E_{2L} - 2E_L) <= C M on the U(1) spin-1/2 class (XXZ ring, any z-field, any z-DM angle, every L >= 2) is refereed proved on J_z/J in [-1 + delta, 0] (C134/C136, C = 6e15 delta^(-25/3)) and on [0, 63/64] (C139 + C140, C = 345600), and holds trivially at J_z/J = -1. Two strips remain, and each reduces to one estimate on the ground-state Bethe roots.

(L*), repulsive side, 63/64 < Delta <= 1. C140 needs L r0(x_n) >= ((2 - ln 2)/pi^2) b = 0.1324 b along the branch, where x_n is the outermost root and b is as in C140 PROOF. It proves L r0(x_n) >= (pi/(8(pi - gamma))) b, which suffices for gamma > 0.176 and tends to 0.125 b at Heisenberg, a 6 percent shortfall. Numerically L r0(x_n)/b >= 0.442 in every case (L from 4 to 1024, all sampled fillings, Delta up to 0.9999). Everything else in the C139/C140 argument is uniform in Delta up to 1. The loss is in C140's pairing of each gap with its adjacent root (only the two roots flanking x are left uncompensated) and in the outer Neumann correction 2(1 - ln 2)/(pi gamma L).

(D), attractive side near Delta = -1, eta = pi - gamma small. C138 Theorem B needs |sigma_L - r_{Q_L}| <= C_D/(eta L) wherever L eta r_{Q_L} >= 4 C_D, uniformly in Delta, L and n, plus the derivative version (D1) and three continuum bounds (W1)-(W3) (C138 PROOF section 4.2). Given these, C <= 628 there. Numerically eta L sup|sigma_L - r_Q| is between 0.23 and 0.32 (L to 8192, 1 + Delta to 1e-6), with the maximum on isolated tail roots, where sigma_L spikes to about 1/(pi eta L). C136's method gives the estimate only with eta L replaced by eta^2 L. The cumulative root error is not uniformly bounded near a Fermi boundary (C138 RESULT), so a proof must work pointwise.

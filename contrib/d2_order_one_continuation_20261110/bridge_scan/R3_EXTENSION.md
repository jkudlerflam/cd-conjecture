# Bounded r=3 field-window extension

2026-11-10. Written before output from these fields, with parent coordination.
The previous contribution sampled r=3,D=1/8 at h=-5/4 (a low-density,
entropy-saturating branch) and h=-7/6 (raw L24 density about 0.44, strong
modulation and c-size near one). The intermediate interval was not resolved.

Use r=3,D=1/8,q=0 and 1/16, and each of the five fields
h=-39/32,-77/64,-19/16,-75/64,-37/32. This is ten full microscopic
Hamiltonians, both exact parities, L24 chi64. Coupling spreads are <=9.75;
all invariant and cancellation measures use the original convention. The
grid spacing is 1/64. A nominal density of 0.275 is a navigation aid only.
If an adjacent pair brackets that density and neither is within 0.015,
at most two exact midpoint rounds per q may follow, down to 1/256 spacing.
All density jumps, parity switches, profiles and convergence errors remain
visible; no branch will be discarded simply because it is inconvenient.

At most three new L48 chi128 parity pairs may be promoted: for each q,
the point with largest minimum of the two profile slopes among n in
[0.2,0.35], plus the q=0 point nearest n=0.275 if distinct. Ties resolve by
smaller profile-window disagreement, then smaller density distance. If a
q line has no point in this density interval, its closest-density point
is a control rather than a flagged lead. The selected list must be frozen
before L48 output. A single-size profile is never a positive final result.

For scheduling, five already selected L48 negative controls from Stage B
may be deferred while the three existing leads and this narrow interval
are checked. `queue_control.json` records the exact deferred names. They
remain part of the registered selection and will be completed subsequently;
the batch log's DEFERRED entry does not represent numerical output.
Any completed two-size lead with c>1 in both entropy windows beyond
numerical errors receives priority for a coordinated L96 check.

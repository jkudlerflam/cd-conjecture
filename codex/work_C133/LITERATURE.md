# Literature audit

[proved, source record] Only the browsing tool was used for literature access. No network shell commands were run. The search was targeted, not exhaustive.

| Primary source | Candidate and exclusion |
| :-- | :-- |
| [Ikhlef, Jacobsen, Saleur, An integrable spin chain for the SL(2,R)/U(1) black hole sigma model](https://arxiv.org/html/1109.1119v2) | [proved, as stated in the source] The finite-dimensional Hamiltonian is non-Hermitian. The Virasoro c can grow, but its identity state is nonnormalizable and its ground-energy effective central charge is 2. Both points prevent the proposed Casimir counterexample. See its spin-chain definition and the paragraph following equation 16. |
| [Dorey, Ravanini, Staircase Models from Affine Toda Field Theory](https://arxiv.org/abs/hep-th/9206052) | [heuristic] Successive RG plateaus are not simultaneous infrared tensor factors. The construction is a continuum scattering/TBA proposal. |
| [Dorey, Ravanini, Generalising the staircase models](https://arxiv.org/abs/hep-th/9211115) | [heuristic] The specified coset staircases do not give a fixed-d microscopic Hamiltonian. Their central charges stay bounded at fixed G,k by the elementary coset formula used in PROOF.md. |
| [Latorre, Sierra, The c-d conjecture](https://arxiv.org/html/2403.17242v2) | [proved, source record] Its examples supply the standard Ashkin-Teller, parafermion and WZW comparison families. Larger directly implemented rank uses larger local dimension. Its c-d conjecture is not used as a proof. |
| [Rajabpour, Cardy, Discretely Holomorphic Parafermions in Lattice Z(N) Models](https://arxiv.org/abs/0708.3772) | [proved, source record] Identifies the FZ critical lattice points and their anisotropic counterparts. This supplies context for the parafermion control, not a fixed-d unbounded multiplicity mechanism. |

[heuristic, conclusion] None of these sources supplies an in-scope fast tower. The noncompact black-hole example is a particularly misleading candidate if c and c_eff are conflated. No broad claim that all possible literature constructions have been excluded is made.

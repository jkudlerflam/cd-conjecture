## Background for the d = 2 runs (C15, C16, C17)

The repository is two levels above your folder (`../../`). Read `../../STATUS.md` first.

**The question.** H = Σ_i h_{i,i+1} on (ℂ²)^⊗L, periodic boundary conditions, one fixed Hermitian h on ℂ² ⊗ ℂ², one-site translation invariance. If the low-energy spectrum is described by unitary CFT(s) with total central charge c (several velocities allowed, c = Σ c_a), is c ≤ 1? The standard is theoretical physics: standard RG and bosonization, controlled perturbation theory, the c-theorem, and numerics calibrated with at least two estimators. Rigor is not required, but every step must be shown and every claim tagged.

**Parametrization.** Up to h → h + o⊗1 − 1⊗o (which leaves H unchanged), an additive constant, overall scale and a global SU(2) rotation, h = Σ_{a,b} J_{ab} σ^a ⊗ σ^b + Σ_a B_a (σ^a ⊗ 1 + 1 ⊗ σ^a)/2 with J a real 3 × 3 matrix (not necessarily symmetric) and B a uniform field: an 8-parameter compact family. The connected operator Schmidt rank of the bond is rank J ≤ 3.

**What is known in the repository** (`../../codex/work_C6_d2/c6.tex`, Astra, partly checked).
- c ≤ 1 is proved on the quadratic Jordan–Wigner locus F (via the free-fermion theorem c = #zeros/4 ≤ rank A(1)/2) and holds given standard input on the U(1)-symmetric locus U and the zero-field XYZ locus X.
- The residual set is R = P \ (F ∪ U ∪ X). Its strata: exactly one unitary Z₂ (4 parameters, open off controlled subloci), only an antiunitary symmetry (two branches, time reversal and plane reflection, 5 parameters each, open), and no nontrivial uniform internal symmetry (8 parameters, open).
- Numerics: exact diagonalization to L = 22 and DMRG found no c > 1 (`../../codex/work_C4_D2/`, `../../contrib/d2_classification/`). The last two suspicious points are incommensurate floating spirals with c = 1.00 and 1.02 from finite-entanglement scaling (`../../contrib/d2_followup_220_1282/`).
- For selection of long spontaneous cells by frustration-free segments, the finite witness length is K_FF(2) = 4, so that route is closed at d = 2 (`../../codex/work_C8/qubit_ff_witness.md`). The cell construction of STATUS.md needs local dimension of order 45 or more.

**Known critical nearest-neighbour qubit families** (literature): XY and XX (Ising c = 1/2, Dirac c = 1), XY with uniform Dzyaloshinskii–Moriya (Ising, chiral c = 1), XXZ in a longitudinal field (Luttinger, SU(2)₁), zero-field XYZ (c = 1), the antiferromagnetic Ising chain in mixed fields (Ising curve, Ovchinnikov et al. cond-mat/0306468), the transverse-field XXZ chain (Ising, special c = 1 regimes, Dmitriev et al. cond-mat/0204590), XYZ in a field written as the interacting Kitaev chain (floating c = 1 phases, an exact c = 1 locus, Ising boundaries; Chepiga and Mila 2206.11754), and the dual ANNNI chain (floating c = 1). Every strictly nearest-neighbour conformal entry known to us has c = 1/2 or 1. Gapless non-conformal points include the ferromagnetic Heisenberg point and saturation or band-edge points (z = 2). With longer range c exceeds 1 easily (cluster models give SO(A)₁ with c = A/2; interleaved XXZ chains give c = R), so nearest-neighbour range is essential.

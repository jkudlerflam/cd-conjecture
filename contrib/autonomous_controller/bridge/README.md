# Autonomous length-to-program-to-circuit bridge

**Status: one explicit, constant-alphabet reversible machine now connects
blank working memory to a length-dependent quantum circuit and back to
blank.** It supplies the missing copy/handoff step of the previous
[standalone length counter](../../controller_instantiation/controller/LENGTH_COUNTER.md)
and demonstrates that program generation, execution, and cleanup can be
composed without host-side changes at the phase boundaries.

This is a small instruction-generation demonstration. It does **not** yet
generate the sparse encoding circuit, instantiate a legal-history
Hamiltonian, or establish a counterexample to the c–d conjecture. Its
local dimension is not the earlier `d=240` fixture's dimension.

The stronger [integrated readout extension](INTEGRATED_READOUT.md) now
splices endpoint transport and safe READY windows into this same cycle,
before its adjoint computation, using one larger collision table. The
base implementation below is retained as a separately checked primitive.

## 1. Initialized contract and exact output

For every `n >= 4`, the static tape is

```text
LEFT BULK ... BULK RIGHT
```

Each site has four dynamic neutral bits: counter, frontier, program, and
cursor. All four start at zero. There is one fresh head at LEFT in control
`F:ADVANCE`. The quantum data, one neutral qubit per physical site in the
demonstration, may be an arbitrary joint state, including an entangled one.

The same machine for every `n` performs:

1. Compute `n−1` in little-endian counter bits on the `n−2` BULK sites,
   leaving the unique frontier on RIGHT and the head on LEFT.
2. Sweep right and apply the reversible copy `program ^= counter` at each
   BULK site. Return to LEFT. The counter is retained and the program now
   contains the binary digits of `n−1`, padded with zeros.
3. Interpret each program bit in left-to-right order. Bit zero means
   CNOT; bit one means controlled-√X, denoted CV. The instruction at physical
   site `j` acts on the quantum registers at sites `(j,j+1)`.
4. At RIGHT, enter reverse execution through a literal table entry.
   Execute the adjoint gates in reverse order, undo the copy, and reverse
   the length computation.
5. Return exactly to the original blank tape, original head, and original
   quantum state. Repeat, with no absorbing halt.

Writing `b_j = ((n−1) >> j) & 1`, `U_0=CNOT`, and `U_1=CV`, the circuit at
the forward midpoint is

\[
U_n=U_{b_{n-3}}^{(n-2,n-1)}\cdots U_{b_1}^{(2,3)}U_{b_0}^{(1,2)}.
\]

The quantum register on LEFT is untouched. CV uses

\[
V=\tfrac12\begin{pmatrix}1+i&1-i\\1-i&1+i\end{pmatrix},\qquad V^2=X,
\]

in its controlled block. CV is not self-adjoint, so the reversal tests
check genuine adjoints. Adjacent gates do not generally commute. This is
therefore a test of gate order and reversible coherent computation, not
just a tally of commuting operations. The control never reads quantum
data. The demo qubits are neutral work records; no fermion-number
conservation assertion is made for these gates.

## 2. Actual finite local dimension

The neutral alphabet is

\[
\Gamma=\{L,B,R\}\times\{0,1\}_{\rm counter}
\times\{0,1\}_{\rm frontier}\times\{0,1\}_{\rm program}
\times\{0,1\}_{\rm cursor},\qquad B=48.
\]

There are fifteen forward control labels and fifteen reverse labels.
The forward labels are:

| Labels | Next move | Oracle |
|---|---|---|
| ADVANCE, CARRY, SCAN, FINAL_CARRY | right | identity |
| BACK, RETURN, FINAL_BACK, FINAL_RETURN | left | identity |
| COPY, DISPATCH | right | identity |
| COPY_BACK | left | identity |
| EXEC_0, EXEC_1 | right | CNOT, CV |
| GATE_BACK_0, GATE_BACK_1 | left | identity |

Each reverse label has the opposite move direction and the adjoint
oracle. Thus `K=30`, independent of `n`. The direct-sum no-head,
fresh-head, and updated-head representation has

\[
\boxed{(1+2K)B=2928}
\]

states per site. Tensoring with one qubit gives **5856** local states.
For a general quantum record of dimension `D`, the factor is `2928D`.
These counts cover this particular composed controller, with all
malformed neutral inputs and head controls included. They do not cover
clock, initialization penalties, sparse-circuit generation, or readout.

[transition_table.json](transition_table.json) contains **every one of the
1440 entries** of the local collision permutation. Of these, 112 are
prescribed algorithmic entries. The remaining entries are completed to a
permutation within each static-mark sector. The static mark is therefore
conserved on every local input, including malformed inputs. The quantum
record is unchanged by collisions.

## 3. Local reversibility and composition

A machine step is a direction-tagged nearest-neighbor move, with its
quantum oracle, followed by collision at the arrival site. The table is
generated by [bridge.py](bridge.py). It imports the earlier counter's
explicit **forward rules**, but does not import that counter's immediate
forward-to-reverse turnaround.

The new handoffs are actual prescribed collisions:

```text
(F:FINAL_RETURN, blank LEFT) -> (F:COPY, blank LEFT)
(F:COPY, frontier RIGHT) -> (F:COPY_BACK, frontier RIGHT)
(F:COPY_BACK, blank LEFT) -> (F:DISPATCH, blank LEFT)
(F:DISPATCH, frontier RIGHT) -> (R:DISPATCH, frontier RIGHT)
```

The reverse counterparts of the first three are generated automatically
as reversed-label inverse collisions. The last entry is the forward
turnaround. At the other end, `(R:ADVANCE, blank LEFT)` maps to
`(F:ADVANCE, blank LEFT)` and closes the entire orbit. No simulator routine
relabels the head or writes the tape between these stages.

The program-copy rule is XOR on both possible initial program values:

\[
(\mathrm{COPY},b,p)\longmapsto(\mathrm{COPY},b,p\oplus b).
\]

In particular, it is not a destructive assignment to an unverified
target bit. It produces a clean copy because the initialized program
track is blank.

The gate dispatcher uses a cursor bit to avoid local merges. At an
unmarked instruction carrying opcode `p`, DISPATCH marks that site and
enters EXEC_p. EXEC_p moves right, applies `U_p`, and changes to
GATE_BACK_p. That label moves left to the marked instruction, where the
unchanged opcode permits erasure of the opcode from finite control and
clearing of the cursor. The head is now in DISPATCH and can move to the
next instruction. The two opcode cases occupy different cursor/program
sectors, so erasure is reversible.

For every nonterminal prescribed forward collision

\[
(q,a)\longmapsto(q',b),
\]

the table includes

\[
(\bar q',b)\longmapsto(\bar q,a).
\]

The bar also reverses the movement direction and takes the oracle's
adjoint. A reverse label is ready to undo its corresponding **move**;
after that move, the inverse collision undoes the preceding forward
collision. This ordering is essential: reversing only the collision
permutation while keeping the same movement labels would not reverse
the computation.

All domain and range pairs are checked for uniqueness before completion.
The two turnaround ranges are unused by the nonterminal rules. Static
boundary symbols distinguish handoffs from scan-loop ranges, while
cursor bits distinguish instruction fetch/return from gate execution.
Consequently completion preserves every intended entry and supplies an
inverse for every malformed local input as well.

## 4. Fresh/updated local gates and exact time

The collision permutation `C` defines an on-site involution `F`:

\[
F:\ |\mathrm{updated},q,a\rangle\mapsto
|\mathrm{fresh},C(q,a)\rangle,
\qquad
F:\ |\mathrm{fresh},q,a\rangle\mapsto
|\mathrm{updated},C^{-1}(q,a)\rangle.
\]

It is the identity in the no-head sector. For each direction-fixed
control, a nearest-neighbor involution `G` swaps the fresh-head and
updated-head locations and applies its oracle in one direction, its
adjoint in the other. The blocks require exactly one head on that bond;
all other local sectors can be set to identity. Different controls and
head phases make the active blocks disjoint.

An ordered left-to-right sweep of `G` moves an initialized fresh head
exactly once. The subsequent on-site `F` sweep applies `C` at the arrived
site and makes the head fresh. Our coherent tests execute these spatial
sweeps, including every possible reverse block, rather than merely
assuming one move per sweep. Every legal head move stays in bounds. In
particular, no missed move is repaired by manually resetting its phase.

The earlier length computation takes

\[
T_{\rm count}=n^2+3n-4-2\operatorname{popcount}(n-1).
\]

Copying and returning takes `2(n−1)` moves. Dispatching each of `n−2`
instructions takes three moves, followed by one move to RIGHT. Therefore

\[
\boxed{T_{\rm forward}=n^2+8n-11-2\operatorname{popcount}(n-1),
\qquad T_{\rm cycle}=2T_{\rm forward}.}
\]

There are exactly `n−2` forward oracle calls and their `n−2` reverse
adjoints. These times count machine steps. An explicit sweep circuit
uses an additional factor of order `n` in the number of local gate
applications; this is not a completed Hamiltonian history-clock bound.

## 5. Checks and precise remaining work

Run:

```sh
python3 contrib/autonomous_controller/bridge/bridge.py --output contrib/autonomous_controller/bridge/transition_table.json
python3 contrib/autonomous_controller/bridge/checks.py
```

[results.json](results.json) records:

- all 1440 collision inputs and inverses, plus static-mark conservation;
- all 2928 classical basis states of `F`, verifying `F^2=I`;
- 2730 direction/control/position cases for the ordered `G` sweep;
- complete autonomous cycles for all 125 lengths `n=4,...,128`, totaling
  **1,541,966 machine steps**, with exact counter and program checkpoints;
- 28 random coherent quantum inputs at lengths four through ten, executing
  **5280 complete spatial `G`/`F` sweep pairs**;
- exact agreement with the independently constructed forward circuit in
  these tests and maximum inverse-cleanup amplitude error below
  `6.3e−17`;
- identical classical trajectories across different quantum inputs;
- a noncommuting-gate negative control, showing that changing oracle order
  does change the quantum output.

The finite checks supplement the rule-by-rule all-length argument; they
are not exhaustive tests of arbitrary global malformed configurations.
The completed local gates are unitary on such configurations, but no
useful computation or energy penalty is claimed for them here.

The next required extension is to replace the binary-digit copying and
short dispatcher with a generator for the actual sparse-encoding
instruction stream, while maintaining these same explicit handoff and
cleanup guarantees. Static marks and the unique initial head must also
be enforced by the initialized-core Hamiltonian. The construction still
needs input verification, quantum workspace preparation, specialization
of the integrated readout to the high-channel output ports, and a final
count of the composed local dimension. This bridge removes an abstract composition step; it
does not remove those remaining obligations or certify an infrared CFT.

## Where things stand

The bound L(E_{2L} − 2E_L) ≤ C M on the U(1) spin-1/2 class is proved on 0 ≤ J_z/J ≤ 1 with C = 4078 (C142, unrefereed), on [−1 + δ, 0] with C = 6·10¹⁵ δ^(−25/3) (C136, refereed) and at −1 exactly. Only the strip −1 < Δ < −1 + δ₀ near the ferromagnet is open. Notation: η = π − γ, Δ = −cos η, crossover parameter ηL.

C142 Theorem II.6 proves, at every point of the occupied interval and every filling, ηL|σ_L − r_Q| ≤ C_D(η) = (4/π)(log(1/η) + π/2), from the representation σ_L − r_Q = ∫ calR_Q(x, y) dR_L(y) (a midpoint-quadrature error) and the uniform variation bound on the restricted dressing kernel. Numerically the true value is at most 0.32 everywhere (L to 8192, 1 + Δ to 1e-6). C142 II.4 locates the logarithm exactly. It comes from the cells at distance between η and 1 from x, where calR(x − y) behaves like (1/(πη)) log(1/|x − y|) and the true per-cell error is second order. A trapezoid bound there removes the log provided σ_L ≥ r_Q/2 on the unit neighbourhood of x and a derivative term is O(1/(ηL)), and both hold once ηL r ≥ C log(1/η) there. On the shell C₀ ≤ ηL r ≤ C log(1/η) the a priori control is too weak, and a naive bootstrap from Theorem II.6 fails because the second-order bound at x needs control on [x − 1, x + 1], which reaches into sparser regions. C138 Theorem A gives L|F − L e_bulk| ≤ (5π/4) ηL unconditionally, and with log-free (D) plus (W1)–(W3), C138 Theorem B gives C ≤ 628. With the logarithm, the two together still diverge like log(1/η).

## Tasks

1. Remove the logarithm. Candidate routes: (a) a multiscale bootstrap that proves the second-order cell bound on dyadic shells in ηL r, propagating control outward from the dense core where ηL r is large, using that the kernel's long-range part is smooth; (b) a direct second-order quadrature bound that uses the monotone counting function and the exact cell masses 1/L instead of a priori pointwise density control; (c) a modified Theorem B that needs (D) only on the region where ηL r ≥ C log(1/η) and controls the shell by Theorem A or by a separate count (the shell contains few roots, so its energy contribution may be bounded directly). Route (c) may be the cheapest: first check what Theorem B actually needs from the shell.
2. Prove C138's continuum bounds (W1)–(W3) (C138 PROOF Section 4.2) uniformly in η and in the Fermi boundary Q, with explicit constants. These concern only the restricted linear integral equation. C142 notes that positivity alone gives (W2) only at distance of order log(1/η) from the Fermi point, and that the uniform version needs Wiener–Hopf suppression of the outer kernel near the edge. Use the explicit Fourier symbol, 1 − T̂(w) = 2cosh(γw/2) sinh(ηw/2)/sinh(πw/2), and its factorization.
3. Referee C138 Theorem B line by line as you use it, since the strip constant rests on it and it has not been refereed.
4. Assemble the theorem on the strip with an explicit δ₀ and constant, and then on the whole U(1) class J_z/J ∈ [−1, 1] with one explicit C, listing which result covers each region and how the seams glue.
5. Test every new inequality numerically with the existing Bethe solvers (copy them into your folder from work_C142 or work_C138), with 1 + Δ down to 1e-6 and L up to a few thousand. Keep numerics on the critical path.

If the logarithm cannot be removed, say exactly which inequality is left, on which set, and its numerical margin.
